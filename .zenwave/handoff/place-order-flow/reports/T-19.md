CHOICES:
- Backoff: due time = failedAt + backoff (5 s / 15 s, picked by attemptCount). The service waits only the remainder from Instant.now(clock), never a negative wait. A null failedAt waits 0. The wait goes through a Consumer<Duration> sleeper, Thread.sleep by default, which tests replace via package-private setSleeper. With the fixed test clock: C-16 waits 0 s and C-17 waits 6 s (recorded, not slept).
- retryPayment is @Transactional(propagation = NOT_SUPPORTED), like authorizePayment, so the wait holds no DB transaction. The save commits on its own.
- On the retried outcome the Payment is saved unchanged, still FAILED, because no field changes.
- No-op on an existing Payment returns Optional.of(existing), the same as the capturePayment redelivery. With no Payment it returns Optional.empty().
- Blocking the consumer thread for up to 15 s is the simplest option for the demo. A scheduler or delayed topic would be the production alternative: a candidate question.
